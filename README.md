# mosaic-collage

A browser app for making mosaics and paper collages. Pieces are made on the **cutboard**: a shape,
texture, colour, relief and torn edge. They are then placed, rotated and locked on the
**workboard**. Mosaics are saved as editable files and exported to JPG or PNG.

**State:** planning. Goal G-001 is in `GOALS.md` and no code has been written yet.

Local only: everything runs in the browser, with no server and no accounts.

How to run: not available yet. Milestone M1 adds `npm run dev`.
